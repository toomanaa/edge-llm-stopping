\begin{itemize}
\item Generation stopping on edge devices is priced in measured joules, not tokens
\item Marginal token cost grows with context, so token-optimal is not energy-optimal
\item Measured on a Raspberry Pi 5: command parsing wastes nothing, open QA wastes real energy
\item Next-token entropy, read correctly, is an informative but imperfect stopping signal
\item First measured-energy study of adaptive stopping on physical edge hardware
\end{itemize}
